# 프로젝트 전역 작업 규칙 (Workspace Rules)

1. **답변 언어**: 모든 답변은 한국어로 작성한다.
2. **배포 즉시 반영 원칙 (GitHub Push)**:
   - 사용자가 요청한 모든 코드 수정 및 PRD 업데이트 작업이 완료되면, 망설이지 않고 즉시 `git add . && git commit -m "..." && git push origin main` 명령을 실행한다.
   - Vercel 자동 배포 환경을 통해 사용자가 실제 웹사이트에서 `새로고침`만으로 즉시 확인할 수 있도록 자동 반영을 보장한다.
